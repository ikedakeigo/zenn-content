# 記事 → リール台本

動画そのもの（Remotion の実装・レンダリング）は `k-grid-reel-to-post` スキルの担当。このスキルは、その入力になる台本を記事から作って `reels/<slug>/` に残すところまでを行う。

## 1. 切り口を1つに絞る

- 記事の全部は載せない。「一番保存されそうな1テーマ」に絞る。
- 切り口の例：「〇〇、説明できる？」「〇〇の裏側」「〇〇 7つのチェック」。
- 案を2〜3個出して、圭吾に選んでもらう。

## 2. reels/<slug>/ に3ファイル作る

`script.md`（シーン表）：

| # | シーン | 背景 | 尺 | 見せる絵 | テキスト | 手書き注釈 | キャラ |
|---|---|---|---|---|---|---|---|
| 1 | フック | 暗 | 5s | | 白見出し（6字前後）＋黄見出し（6〜8字） | | thinking |
| 2〜6 | 本文 | 明 | 6〜9s | 図解・実物 | タイトル12字以内／解説3行（1行18字前後） | 1つまで | |
| 7 | まとめ | 明 | 6s | チェックリスト5項目 | | | celebrate |
| 8 | CTA | 暗 | 5.5s | 当てはまる4項目 | 「全手順はプロフのリンクから」 | | notify |

- 合計40〜60秒。最後に必ず「全手順はプロフのリンク（Zenn）から」を入れて記事に誘導する。
- 文字数は全角1・半角0.5で数え、上限を超えたら短くする。

`caption.md`：

```
<フック1行>
<この動画で分かること 3〜5行>
<一言／問いかけ 1行>
全手順はプロフのリンク（Zenn）にまとめました
保存してあとで見返してね
#ハッシュタグ 8個前後
```

`sources.md`：台本の数字・仕様の確認に使った一次情報のURL。

## 3. 記事側を更新する

- 記事冒頭の :::message を「リールで紹介した内容の完全版です」の形にする（無ければ追加）。
- `ideas.md` のリール欄を「台本済み」にする。

## 4. 動画化へ渡す

- `k-grid-reel-to-post` スキルが使えるなら、`reels/<slug>/script.md` を渡して実装に進むか圭吾に聞く。
- Remotion リポジトリ（k-grid-reel）の場所は `CLAUDE.local.md` に書いてある。無ければ圭吾に聞いて追記してもらう。

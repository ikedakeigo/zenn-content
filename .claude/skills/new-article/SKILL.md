# Zenn記事を書く

## 1. テーマを決める

- `ideas.md` にあるネタならそれを使う。無ければ追記する。
- 次の3点を1回だけ確認する（わかっていれば聞かない）：
  1. 誰の、どんな困りごとを解決する記事か
  2. 元になるリール・作業ログ・リポジトリはあるか
  3. 手順記事（tech）か、考え方の記事（idea）か

## 2. 構成案を出す

- `.claude/rules/article-style.md` の「構成の型」に沿って、見出しと各見出しで書くことを1行ずつ出す。
- タイトル案を3つ出す（検索される言葉を前半に）。
- slug 案を出す（12〜50字、半角英小文字・数字・ハイフン）。
- ここで圭吾の OK をもらってから本文に進む。

## 3. 下書きを書く

```bash
npx zenn new:article --slug <slug>
```

- 作られたファイルに frontmatter と本文を書く。`published: false` のまま。
- 仕様・コマンドは公式ドキュメントで確認し、確認したURLを控える。
- 実体験・感想・スクショは `<!-- TODO: ここに〇〇を書く（例：…） -->` で空ける。
- 画像が必要な場所は `<!-- TODO: 画像 images/<slug>/01-xxx.png（何を写すか） -->` と書く。

## 4. 推敲する

- 一文60字超、同じ語尾の3連続、専門用語の説明漏れを直す。
- コードを実行できるものは実行して確かめる。
- CLAUDE.md の「公開前チェック」を実行し、結果を一覧で報告する。

## 5. 報告する

- 記事のパス、`npx zenn preview` で見るURL（http://localhost:8000/articles/<slug>）
- 残っている TODO の一覧
- 検証済み／未検証のコード
- 「この記事はリールにできそうか」の一言（できるなら `/article-to-reel` を提案）
- `ideas.md` のステータスを「下書き」に更新する

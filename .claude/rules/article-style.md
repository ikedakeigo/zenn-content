# Zenn記事の書き方

## frontmatter

```yaml
---
title: "（32〜40字目安。検索される言葉を前半に入れる）"
emoji: "📝"            # 絵文字1つ
type: "tech"           # 手順・実装は tech、考え方・振り返りは idea
topics: ["claudecode", "ai"]   # 最大5個。半角英小文字・数字。既存の人気トピックを優先
published: false       # 公開は圭吾が true にする
---
```

- よく使う topics：`claudecode` `ai` `kintone` `typescript` `nextjs` `react` `obsidian` `生産性`
- 予約公開したいときは `published: true` と `published_at: "YYYY-MM-DD HH:mm"` を圭吾が設定する。

## 文体

- **です・ます調（敬体）**。一文は60字以内を目安に、長くなったら分ける。
- 一人称は「私」。読者は「〜な人」と書き、「皆さん」は使わない。
- 主張 → 理由 → 具体例（コード・画面）の順で書く。「なぜそうするか」を必ず1文入れる。
- 誇張しない（「爆速」「最強」「神」は使わない）。数字で言えるところは数字で言う。
- 用語は初出で一言説明する（例：「スキル（Claude Codeに渡す手順書のようなもの）」）。

## 構成の型

```markdown
## この記事でわかること      # 箇条書き3つ
（導入：困っていたこと → この記事で何ができるようになるか。3〜5行）
:::message
Instagram（@k_grid_blog）のリールで紹介した内容の完全版です。…
:::
## 全体像                    # 図・ディレクトリ構成・流れ
## 手順 / 仕組み              # ### 1. 〜 のように番号付き
## ハマりどころ               # あれば。実体験ベース
## 実際に使ってみて           # TODO で圭吾の言葉を待つ
## まとめ                    # 箇条書き3つ
（末尾の導線）
```

- 見出しは `##` から始める（`#` はタイトルと重なるので使わない）。
- 手順記事は「前提（環境・バージョン）」を冒頭に書く。

## Zennの記法

- 補足は `:::message`、注意は `:::message alert`、長いログや全文は `:::details タイトル` で折りたたむ。
- コードブロックにはファイル名を付ける：```` ```ts:src/main.ts ````。差分は ```` ```diff ts ````。
- 画像：`![説明](/images/<slug>/01-overview.png)`。ファイル名は連番＋内容。説明（alt）を必ず書く。
- 表は3列以内に収める（スマホで読まれるため）。

## インスタへの導線（定型）

冒頭の :::message（リール起点の記事のとき）：
> Instagram（@k_grid_blog）のリールで紹介した内容の完全版です。リールでは要点だけを話しているので、ここでは〇〇まで解説します。

末尾：
> Instagram [@k_grid_blog](https://www.instagram.com/k_grid_blog/) では、Claude Code×AI開発の実践ネタを発信しています。

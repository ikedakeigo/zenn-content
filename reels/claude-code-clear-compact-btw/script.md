# 同じミス、何回直してる？（/clear・/compact・/btw）

## 企画の狙い

- **誰の何を解決するか**：Claude Code に同じミスを何度も直させてしまい、時間を溶かしている人の「直しても直らない」を解決する
- **リールで持ち帰れる学び**：2回直してダメなら `/clear` して、学んだことを足してやり直す。関係ない作業なら `/clear`、続けるなら `/compact`、ちょっと確認は `/btw`
- **記事で追加して得られること**：やり直しプロンプトの具体例（ゴール・場所・避けたいやり方）、`/clear` 後も前の会話は `/resume` で戻れること、`/rewind` の注意点、`/btw` の制約、CLAUDE.md の要約ルールの書き方
- **今後もフォローする理由**：コンテキスト管理シリーズ（①AIの記憶の置き場所 → ②CLAUDE.md に書くこと → ③会話の掃除）の3本目。次はサブエージェントに調査を任せる回
- **今回試す変更（1つ）**：CTA を「@k_grid_blog をチェック」から「全手順はプロフのリンクから」に変え、記事への導線を作る

## 実装

- Remotion：k-grid-reel リポジトリの `src/cleanup/`（Composition `CleanupReel`）
- 1080×1920・30fps・59.3秒・9シーン。シーン間のトランジション 12f（暗↔明は fade、明→明は slide）
- 書き出し：`npm run render:cleanup` ／ カバー：`npm run cover:cleanup`（フックの 140f）

## 公開前の確認

- **記事を公開し、プロフィールのリンクから記事に届くことを確認するまで、リールは投稿しない**（動画のCTA・ナレーション・キャプションのすべてが記事へ誘導しているため）
- シーン2の「ログイン後は /dashboard へ戻して」は説明用の例。実際に `/clear` してやり直したときのプロンプトに差し替えると実体験になる（顧客名・案件名は出さない）
